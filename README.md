# ig.news

![TypeScript](https://img.shields.io/badge/TypeScript-3178C6?logo=typescript&logoColor=white)

## About

Subscription-based news platform built with Next.js: GitHub login via NextAuth, Stripe subscriptions with webhooks, FaunaDB persistence and Prismic-managed content. Rocketseat Ignite project.

## Tech Stack

- TypeScript
- Next.js
- React
- FaunaDB
- Stripe
- NextAuth
- Prismic CMS
- axios
- Sass

## Getting Started

```bash
git clone https://github.com/walteribeiro/ig.news.git
cd ig.news
npm install
npm run dev
```
